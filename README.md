# Ланка

Frontend MVP для хакатону. React + Vite + TypeScript, Tailwind CSS, Motion і React Router. Епохи й репліки оповідача зберігаються в JSON. Сайт не потребує API, ключів або бази даних.

## 1. Запустити на Windows

Встанови Node.js LTS із https://nodejs.org/ (мінімум 22.12 для лінійки Node 22). Розпакуй ZIP. Відкрий папку, де лежить package.json, і вибери «Відкрити в терміналі».

```powershell
node --version
npm.cmd ci
npm.cmd run dev
```

Відкрий адресу Local, яку надрукує Vite. Перевір шлях «Головна → Маршрут → Почати мандрівку → Наступна зупинка». Повернись на маршрут, відкрий авангард напряму й зміни стиль гіда.

## 2. Зібрати для публікації

Зупини dev-сервер через Ctrl+C. У тій самій папці запусти:

```powershell
npm.cmd run build
```

Команда спочатку перевіряє TypeScript, потім створює dist.

## 3. Опублікувати

1. Відкрий https://app.netlify.com/drop і увійди, якщо потрібно.
2. Перетягни папку dist. У її корені має бути index.html.
3. Скопіюй опубліковану адресу HTTPS. Відкрий її на телефоні через мобільний інтернет.
4. Згенеруй QR для цієї адреси та відскануй його іншим телефоном перед хакатоном.
5. Для оновлення збери dist повторно і завантаж його в розділі Deploys того самого проєкту.

HashRouter зберігає внутрішні адреси після символу #. Посилання на епоху можна відкрити напряму без rewrite-правил на сервері.

## Розпізнавання картин (екран /scan)

Працює повністю в браузері: модель DINOv2-small (transformers.js) рахує вектор фото й порівнює його з `src/data/embeddings.json`. Описи — у `src/data/artwork-descriptions.json`.

Після додавання або заміни файлів у `src/artworks` перерахуй індекс (потрібен інтернет для завантаження моделі і Node 22.18+, бо скрипт — це `.ts` без компіляції):

```bash
npm run embeddings
```

Пороги збігу — у `src/scan/recognize.ts`. Підбирались на синтетичних спотвореннях, тож перевір їх на реальних фото з музею.

## Ланка-Гід: чат і голос

Екран `/guide` відкривається після розпізнавання картини. Відповіді на запитання генерує модель через окремий бекенд, адреса якого задається під час збірки:

```bash
VITE_GUIDE_API_URL=http://localhost:8080 npm run dev   # або у .env.local
```

Без `VITE_GUIDE_API_URL`, а також коли бекенд недоступний, гід відповідає локально (готові відповіді за ключовими словами) і позначає це в чаті.

Контракт бекенда: `POST {VITE_GUIDE_API_URL}/guide` з тілом `{ "work": "<файл картини, напр. hay-market.jpg>", "messages": [{ "role": "user" | "guide", "text": "…" }] }` (перше й останнє повідомлення — `user`). Відповідь — потік SSE: події `data: {"text":"…"}`, наприкінці `data: {"done":true}`, у разі збою `data: {"error":"…"}`. Ключ API моделі має жити лише на бекенді, а не у фронтенді.

Голос: кнопка мікрофона в стрічці введення використовує розпізнавання мовлення браузера (`SpeechRecognition`, `uk-UA`; Chrome, Edge). Запитання відправляється після ~1,8 с мовчання. Де API немає, кнопки просто нема.

## Де редагувати

- src/data/epochs.json — хронологія, митці, твори та кольори.
- src/data/narrators.json — режими оповідача та демо-репліки.
- src/Timeline.tsx — SVG-траєкторія й анімація Motion. Точки та траєкторія залежать від порядку в JSON.
- src/App.tsx — екрани й маршрути.
- src/styles.css — тема та адаптивна верстка.
